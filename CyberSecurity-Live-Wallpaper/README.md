# 🕶️ Cyber Security Club - Black Hat Live Workstation Wallpaper Suite (Final v3.0)

A state-of-the-art cybersecurity live wallpaper for your Windows laptop featuring a black hat hacker whose **fingers continuously type on the keyboard**, with **all monitor screens actively updating in real time**, tactical gridlines, and a minimal digital clock.

## 🚀 How to Use with Lively Wallpaper (Recommended)

1. Open **[Lively Wallpaper](https://rocksdanister.github.io/lively/)** (free on Microsoft Store or GitHub).
2. Click **Add Wallpaper** (+) at the top.
3. Choose **Browse** and select [`index.html`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/index.html), or simply **drag and drop** the entire [`CyberSecurity-Live-Wallpaper`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper) folder directly into Lively.
4. Lively Wallpaper automatically reads [`LivelyInfo.json`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/LivelyInfo.json) and [`preview.png`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/preview.png). What you see in `preview.png` is **exactly 1:1 what renders on your desktop**.

## ⚡ Alternative Standalone Modes

### 1. 1-Click Desktop Wallpaper (Zero Third-Party Apps)
- **Start**: Double-click [`Start-Live-Wallpaper.bat`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/Start-Live-Wallpaper.bat) to run native behind desktop icons.
- **Stop**: Double-click [`Stop-Live-Wallpaper.bat`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/Stop-Live-Wallpaper.bat).

### 2. Windows Screensaver (`.scr`)
- Right-click [`CyberMatrixScreensaver.scr`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/CyberMatrixScreensaver.scr) → Click **Install**.
- Or run [`Install-Screensaver.bat`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/Install-Screensaver.bat). If the `.scr` file is missing, the installer uses the native wallpaper executable, which supports screensaver mode.
- To start it immediately, run [`Start-Screensaver.bat`](file:///c:/SECURITY%20CLUB%20STATIC%20PAGE/CyberSecurity-Live-Wallpaper/Start-Screensaver.bat).

## 🎯 Master Features
- **Continuously Moving Hacker Fingers**: Seamless multi-frame mechanical keyboard typing animation with physical recoil and individual keycap backlight flashes under the striking fingertips (140+ WPM).
- **All Screens Moving Continuously**:
  - **Center Monitor (Exploit Studio)**: Rapid character-by-character typing of zero-day Python exploit code (`EXPLOIT_PAYLOAD.PY`), rotating global radar sweep with red attack blips, live attack console logs, and streaming hex memory dumps.
  - **Left Curved Monitor**: Fast-scrolling GDB kernel disassembly trace (`mov`, `test`, `jz`, `syscall`, `call`).
  - **Top Vertical Monitor**: Real-time 64-bit CPU registers (`RAX`, `RBX`, `CR0`, etc.) updating hex values + bouncing waveform bars.
  - **Desk Laptop Screen**: Live Wireshark packet capture sniffer (`TLSv1.3`, `SSH`, `DNS`).
  - **Floating Holographic HUD**: Live oscillating cyan sine wave and target node status in front of the hacker's chest.
  - **Smartwatch on Wrist**: Live glowing heartbeat / CPU load counter (`138 BPM`).
- **Tactical Grid**: High-contrast 52px cyan/emerald cyber grid with crosshair intersection dots.
- **Dynamic Background Data**: Sparse, slow-moving binary and hexadecimal data streams remain behind the hacker without obscuring the scene.
- **Live Remote Node Panel**: A compact bottom-right display cycles through private IP addresses as an active network monitor.
- **Desktop Icon Ergonomics**: Left portion has deep vignette shading so all Windows desktop icon names remain completely legible.
- **Minimal Telemetry & Quick System Shortcuts Dropdown**:
  - Live red 7-segment digital clock with running milliseconds and session mode.
  - Interactive cybersecurity operations calendar with DEFCON threat schedule.
  - **Bottom-Right Dropdown Arrow**: Clickable quick system shortcuts menu with options for **Power Off**, **Go to Settings**, **Restart**, **Lock**, **Sleep**, **Open Task Manager (`Ctrl+Shift+T` / `Ctrl+Shift+Esc`)**, and **Restart Graphics Driver (`Ctrl+Win+Shift+B`)** featuring authentic Windows DWM buffer reload audio beep and screen flash.
